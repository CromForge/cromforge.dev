# cromforge.dev

The Crom Forge website (GitHub Pages, served from `site/` by the Pages workflow): the home page and the Purrsweeper privacy policy (EN/ES).

Rebuild after editing the policy: `python build.py`. Needs `markdown`; the source is the Purrsweeper repo's `docs/release/PRIVACY_POLICY.md`, copied to `_policy_src.md`.
